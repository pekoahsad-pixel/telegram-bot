# Telegram-бот с проверкой подписки на канал

Бот на **aiogram 3.x** с обязательной проверкой подписки на Telegram-канал при команде `/start`.

## 📁 Структура проекта

- `main.py` — основной код бота и логика проверки подписки
- `config.py` — настройки и чтение переменных окружения
- `.env` — файл с токеном бота и ссылкой на канал
- `run.bat` — скрипт для быстрого запуска в Windows двойным кликом
- `requirements.txt` — список зависимостей
